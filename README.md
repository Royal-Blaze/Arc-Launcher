## ✨ Features

- 🎨 Modern JavaFX user interface
- 🚀 Fast startup and low resource usage
- 📦 Multiple Minecraft version support
- 🔧 Automatic Java detection
- ☁️ Microsoft account authentication
- 🎮 Forge, Fabric, NeoForge & Quilt support
- 📁 Custom game directories
- 💾 Instance management
- 🎨 Theme support
- 🔄 Automatic launcher updates
- 📜 Integrated logs
- 📡 Download progress tracking
- ⚡ Optimized performance

## 📥 Installation

### Windows

1. Download the latest release.
2. Run the installer.
3. Launch Arc Launcher.

### Linux

1. Download the latest `.deb` or `.tar.gz`.
2. Install the package.

```bash
sudo dpkg -i ArcLauncher.deb
```

or

```bash
tar -xzf ArcLauncher.tar.gz
```

## 🚀 Building

Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/arc-launcher.git
```

Enter the project.

```bash
cd arc-launcher
```

Build with Gradle.

```bash
./gradlew build
```

Run.

```bash
./gradlew run
```
